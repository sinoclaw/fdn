# 自生长 FW 探针：把 DCA "按需 spawn" 下沉成计算原语（结构训练产出）

> **作者**：陈亦安（安安）
> **背景**：爸爸两次纠正。①去"同参数对齐"（动态/稀疏架构的价值=参数效率，非等参数）；②"我们的参数不是训练自己产生的吗？"——现 FW 结构（N/k/层/宽）是我预设的，只有权重训练学，**结构不是训练产出的** → 不是真动态。
> **目标**：让 **N 个槽（cap）在训练中自己长出来**（从少到多、按需增量、每槽独立路径），结构是训练过程的产物。这才是"区别于 Transformer + 参数少能力不输"的本质。

---

## 1. 核心机制（下沉 DCA spawn 到 token 计算层）

### (a) 动态槽池（从少到多）
- **初始化**：少量槽（如 N0=4），不是预设 16。
- **按需 spawn**：训练中监测——若当前槽对某数据分布学习不足（如 loss 高 / 槽被多任务争用 / novelty 高），则**追加一个新槽**（真 append，ΔParams>0）。
- spawn 判据（复用 DCA 已验证原则）：**"复用是否伤旧"** 而非单看 loss（简单任务 fit 无区分度）。

### (b) 每槽独立计算路径（FastWeights v3 思想，DCA 三判据之一）
- 每个新建槽 = 独立 q/k 投影 + 独立槽方向，**不共享中间表征** → 新槽学习不覆盖旧槽（复用伤旧→新建）。
- 保留 soft-sparse 门控（可导）——这已由探针证明能训。

### (c) 激活自适应
- k（每 token 激活槽数）随当前槽数自适应，而非固定 3。

## 2. 判据（判据先行，跑前锁死）

### 生长判据（真动态，机制发生）：
- **G1 真增长率**：训练后槽数 N_final > N0，且 ΔParams>0（真 append，非预分配池掩盖）。**"能跑"≠"已验证"——须证机制真实发生。**
- **G2 独立路径**：新槽是独立计算路径（测旧槽能力不被新槽覆盖；spawn 因"复用伤旧"而非"学不会"）。

### 价值判据（对照 TF）：
- **G3 参数效率（去同参数对齐）**：**更少参数 + 能力不输**。具体：自生长 FW 在**等训练预算**（非等参数）下，用**显著更少参数**达到 **val ≤ TF 同等能力**。这才是"参数少能力不输"。
- **G4 稀疏性**：激活槽占比低（真稀疏，非稠密）。

### 组合判定（机制 + 价值）：
- **G1+G2 成立** → 结构是训练产出的（真动态），机制达成。
- **G3 成立** → 参数效率>TF（参数少能力不输），价值达成。
- **G1+G2+G3 全成立** → **自生长 FW 走通**：真动态 + 参数效率双赢，值得作为研究方向。

## 3. 实验设计（一次只动一组变量）

1. **字符级语言建模**（同数据）。
2. **对照**：TF（同预算）。
3. **实验**：自生长 FW——自适应槽池，按需 spawn，测 G1（槽数增长）/G2（独立路径）/G3（参数 vs 能力）/G4（稀疏）。
4. 固定：数据、block、batch、lr、seed；只变"是否自生长" vs "预设槽数"。
5. ≥3 seed。

## 4. 诚实边界（事前锚定）
- **G1/G2 是机制判据**——成立才配谈"真动态"；不成立则记录"槽不生长/不独立"，如实暴露。
- **G3 是关键价值**——若自生长 FW 参数更少但能力也差，如实记录"参数效率未兑现"，不硬凑。
- 若自生长 FW 赢得参数效率 → 说明"按需 spawn"下沉成功，进入下一步（找对标模型/蒸馏）。
- 若自生长反而更差 → 如实记录"CPU+字符级 toy 上按需生长无益"，定性同 GSLM 容量饱和教训。

## 5. 与父目标对齐
父目标 = "找区别于 Transformer 的范式，能力不输 + 训练/推理成本双降"。
- **真动态**（结构训练产出）= 区别于 Transformer 的本质。
- **参数效率**（参数少能力不输）= 成本双降的载体（参数少→存储/训练/推理都省）。
- 自生长 FW 直接检验这两点能否同时成立。
