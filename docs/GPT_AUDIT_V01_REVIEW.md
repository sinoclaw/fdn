# **Dynamic Routing 本身可能破坏了优化。**

尤其是你们现在：

```
逐样本
    ↓
Top-K Router
    ↓

    ↓

```

这和普通 dense MLP 最大区别就是：

> **一个 Node 学到的梯度只覆盖部分样本，而且 Router 同时也在变。**

于是出现经典的鸡生蛋问题：

```
Router 不知道谁擅长 A
    ↓
随机分配 Node
    ↓
Node 得到的训练信号不足
    ↓
Node 学不好
    ↓
Router 更不知道该选谁
    ↓
……
```

**不要继续关 dynamic memory / plasticity / τ / k。**

### v0.2 应该这样：

```
                FDN
                 │
       ┌─────────┴─────────┐
       │                   │
 Dynamic Structure      Dynamic Dynamics
       │                   │

       │                   │

                 ↓
          Dynamic Router
                 ↓
              Top-K
```

**只把结构演化限制住，不要把动态学习机制关掉。**

```

```


这才是真正测 **continual dynamic learning**。
