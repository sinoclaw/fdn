# DCA-v1 研究方案：从"数学函数"到"真实神经技能"的尺度跃迁（判据先行）

> **作者**：陈亦安（安安）
> **依据**：GPT 六审（docs/GPT_AUDIT_V09.md）明确——toy 阶段收工，唯一方向 = **DCA-v1：把 Capability 从"数学函数"升级成"真正的神经技能"**，验证"复用/spawn/freeze"原则能否从 ADD/MUL 世界**跨到语义技能世界**。
> **诚实定位**：这是"科研玩具 → 架构研究"的**第一步**，不是"10B LLM 已实测"。受 CPU（8 核无 GPU）约束，用**真实但小型**的神经技能任务。

---

## 0. 为什么这是下一步（GPT 六审的核心指引）

> "再加 XOR、再加几个 toy task、再调一个 loss，科研收益已经非常低。下一阶段应该发生一次真正的尺度跃迁。"
> "把 Capability 从'数学函数'升级成'真正的神经技能'：文本分类 / JSON 提取 / 数学计算 / 代码变换。"
> "我们真正想看的是：**DCA 的'复用 / spawn / freeze'原则，能不能从 ADD/MUL 世界跨到语义技能世界。** 能=真正的研究突破；不能=至少知道它是 toy-specific。"

## 1. 研究问题（一句话）

> **DCA 的三条核心原则（能力路径独立 / 隔离看"复用是否伤旧" / 复用优先于新任务 fit）在"语义技能"任务上是否仍然成立？**

### 1.1 从"数学函数"到"神经技能"的本质差异
| 维度 | 数学函数（toy，已验证） | 神经技能（DCA-v1 目标） |
|---|---|---|
| 输入 | 连续数值向量 (a,b) | 离散符号序列（文本/结构）|
| 任务 | 数值回归（add/mul/sub/logic/seq）| 语义分类/抽取/推理/变换 |
| 能力表征 | 数值分布统计 | **语义表征**（embeddings/特征）|
| 能力边界 | 计算类型（加/乘/减/布尔/序列）| **技能类型**（分类/提取/推理/变换）|
| 伤害度量 | 旧任务 acc 下降 | 旧技能精度下降（需定义）|

**核心**：toy 验证了"独立计算路径 + 复用是否伤旧"在数值域有效；DCA-v1 要验证它**跨到语义域依然有效**，否则 DCA 就是 toy-specific。

---

## 2. 任务集设计（真实但 CPU 可跑）

**选型原则**：① 真实语义/结构任务（非数值回归 toy）；② CPU 可训练（小型模型/浅层表征）；③ 能形成"同族可复用 / 异族需新建"的清晰能力边界；④ 公开可复现数据。

### 4 类神经技能（各含变体用于测复用）
| 技能族 | 任务 | 数据 | Capability 表示（CPU 可跑） |
|---|---|---|---|
| **文本分类** | 情感二分类 / 主题多分类 | IMDB / AG News（子集）| 词袋+tfidf → 小 MLP 头 |
| **结构化抽取** | 从句子抽命名实体 / 抽 JSON 字段 | 简单 NER / 规则化抽取 | 字符+词特征 → MLP 头 |
| **数学推理** | 算术应用题求解（数值）| 简单 word-problem 集 | 特征编码 → MLP 头 |
| **序列/代码变换** | 简单程序/序列变换 | 小规模代码片段 | token 化 → 小 transformer/MLP |

> ⚠️ **诚实约束**：CPU 上不用大型 LLM 做这些技能（那只会有"表征成本极高"的叠加干扰）。用**小型可训练模型**代表"神经技能"，聚焦验证 DCA 的**能力生命周期机制**（复用/spawn/freeze），而非技能本身的精度上限。

---

## 3. 核心判据（跨世界成立的门槛）

### 判据 A：能力边界发现（同族复用 / 异族新建）
- **同族**技能（如 情感分类 + 主题分类，都是"文本分类族"）→ 若复用不伤旧 → 同一 Capability。
- **异族**技能（文本分类 vs 数学推理）→ 复用必伤旧 → spawn 新 Capability。
- **达标**：能力分化矩阵正确（同族共享 cap、异族独立 cap），与 toy 版一致。

### 判据 B：Interference Predictor 在语义域仍能预测 damage
- 用语义技能的 task_rep（从文本/结构特征派生）+ cap_state → 预测 damage。
- **达标**：未见 (cap, skill) 组合上 Spearman ≥ 0.7、REUSE/SPAWN 一致 ≥ 0.8、F1 ≥ 0.8。
- 关键风险：**语义任务的 task_rep 是否可区分**（toy 上输入统计能分 add/mul；语义上文本特征能否分"分类/抽取"？）——**这是本次最核心的待验证点**。

### 判据 C：持续学习（保旧 + 学新）
- 学技能 B 后，技能 A 不遗忘（旧技能精度保持）；B 本身学会。
- **达标**：A_forget ≈ 0 且 B 达到合理精度（真实任务精度阈值需校准，因非完美可分）。

### 判据 D：多 seed 稳定
- ≥3 seed 结果一致（非单 seed 偶然）。

## 4. 方法框架

### 4.1 Capability（神经技能）
每个 Capability = 独立的小模型（特征编码 + 输出头），完全独立路径（不共享中间层）——沿用 FastWeights v3 的"独立路径"设计。

### 4.2 task_rep（语义表征，无 oracle）
从技能数据本身提取语义特征：
- 文本：词频/句长/标点/词性分布/token 多样性 → 固定向量（**不用任务名**）
- 结构：字段数/键名集合/嵌套深度 → 固定向量
- 数学：问题长度/数字个数/运算符集合 → 固定向量
- 核心：**task_rep 要能区分"技能族"**（分类/抽取/推理/变换），这是 predictor 能跨域预测的前提。

### 4.3 Interference Predictor（跨域）
`[task_rep(语义); cap_state]` → MLP → predicted damage → REUSE/SPAWN。
**训练集**：离线真实 probe 生成的 ground-truth（多技能 × 多 cap）。

### 4.4 流程
```
新技能 → Interference Predictor(语义 task_rep + cap_state) → predicted damage
  → REUSE（若伤小）/ SPAWN（若伤大）→ 训练 → FREEZE → Capability Pool
```

## 5. 风险与诚实边界

### 5.1 已知风险（判据先行，提前说清）
1. **task_rep 区分度风险（最大）**：语义任务的特征统计可能**不足以区分技能族**（toy 上 add/mul 分布可区，但文本分类 vs 数学推理的统计特征可能相近）。**若判据 B 因 task_rep 无区分度而失败**——这本身就说明"DCA 跨世界需要更强的语义表征"，是**有价值的反证**，不是失败。
2. **精度阈值校准**：真实任务非完美可分，acc 阈值需先校准（先跑单技能学到上限），避免误判"没学会"。
3. **CPU 算力**：小型模型可跑，但真实语义任务的收敛需更多 epoch；单技能训练时长需先评估。

### 5.2 诚实的边界（贯穿始终）
- 本方案**不宣称**"DCA 已解决持续学习"或"通用智能"。
- **能宣称的**（若判据达标）："DCA 的复用/spawn/freeze 机制，在**小型真实神经技能**（文本分类/结构抽取/数学推理）上仍能自动发现能力边界、复用同类、为异类扩容、保持旧技能——即**不是 toy-specific**。"
- **若判据失败**："DCA 机制在 toy 数值域成立，但在真实语义域受限于 task_rep 区分度——需要更强的语义表征/度量学习，DCA 是否是通用架构待进一步研究。"（如实记录，不硬圆）

## 8. 结论

DCA-v1 是**从科研玩具 → 架构研究的尺度跃迁第一步**。它验证的不是"再加一个 toy 任务"，而是：
> **DCA 的"每能力独立路径 + 复用是否伤旧 + 自动能力边界"这套原则，到底是 toy-specific，还是可跨到真实神经技能的通用机制。**

判据 A/B/C/D 全达标 → DCA 获得跨域普适性证据，值得更大规模；任何一条失败 → 获得"边界在哪"的诚实答案（也费不了几个月，符合 GPT 六审"不至于浪费几个月"的预期）。
