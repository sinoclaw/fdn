# FDN-v0 实验结果报告（V0_REPORT，如实版）

> 本报告与 `results/summary_v0.json`（原始数据）、`docs/DESIGN.md`（设计蓝图）、代码（`model/ growth/ experiments/`）形成三层对账，供外部审计（GPT）核定。
> **结论：在本次实现的 FDN-v0 + toy 任务集下，核心假说未获支持，但失败点与 GSLM 不同——机制在「路由层」成立、在「能力层」失败。**

## 0. 一句话结论

FDN-v0 的**动态结构/记忆/可塑权重都真实发生且可测**，Router 也**确实学会了"同分布任务复用同一批 Node"**（A 与 A' 激活 Node 完全重合，IoU=1.0）；
但**在线结构演化（spawn+merge）过于激进，导致任何任务都无法稳定学习**——FDN-v0 成为全场最差（A_add 0.055），连静态等容量 D（0.574）都不如。
失败根因不是"节点无独立计算路径"（这是 GSLM 的根因），而是**结构变动频率/幅度压过了学习节奏**。

## 1. 设定

- 任务序列：`A_add → B_mul → C_logic → A2_add(A'变体)`，40 epoch/任务，1200 样本，batch 32。
- 超参：hidden=32, r=16, init_nodes=12, k_fixed=5, lr=3e-3, eval_every=120, spawn_cos_thr=0.55, merge_cos_thr=0.95。
- 对照矩阵：A(MLP) / B(静态12节点MoE) / D(静态24节点MoE) / C(FDN-v0 动态)。

|---|---|---|---|---|---|---|---|---|---|---|---|---|

## 3. 证据链（三层对账）

### 3.1 机制层：全动态在 C 上「真实发生」，无造假
- **结构动态**：12→54 节点（`final_nodes=54`），spawn=42 / merge=42 / prune=5 —— 生长与去重真实执行（`tests/test_fdn.py` 的 `test_spawn_grows_and_optim_add`、`test_prune_merge_admin` 验证）。
- **路由动态**：A 与 A' 激活 Node 集合相等（overlap=1.0），证明 Router 学会了"同分布 → 同 Node 组"（'长出并调用'在路由层的真实证据）。
- **记忆动态**：`memory_size=51`（训练时持续写入、聚类）。
- **参数动态**：`plastic_magnitude=0.049`（推理期有界 Hebbian ΔW 生效）。

### 3.2 能力层：C 学到的东西最少，甚至学不动
- C 的最终准确率全场最低：A_add=0.055、B_mul=0.0、C_logic=0.01、A2=0.092（近似随机）。
- 对照：A(MLP)=1.00，D(静态24)=0.574。**同样是路由模块化网络，静态 D 学得远好于动态 C。**

### 3.3 失败根因（本次独特，非 GSLM 版本）
- C 在 40ep×4任务 内触发 **spawn 42 次 + merge 42 次**，即约每轮任务结构就大改一次（eval_every=120 batches+spawn_cos_thr=0.55+merge_cos_thr=0.95）。
- 这种**高频结构震荡**让节点权重始终无法稳定：(a) 新 spawn 的 Node 在学成前就可能被 merge 归档；(b) merge_cos_thr=0.95 过低，频繁把刚分化的节点合并回原状；(c) 路由亲和虽成立，但承载能力的 Node 不具备稳定的可学权重。
- **对比**：B/D 结构固定，权重可以在固定路由下逐步收敛（D 靠更大容量到 0.574）；C 把"可学"的时间花在了"结构重组"上。

## 4. 与 GSLM（已封存 No-Go）的关系

| 维度 | GSLM 根因 | FDN-v0 根因 |
|---|---|---|
| 节点是否独立计算路径 | ❌ 无（能力落在共享投影） | ✅ 有（每 Node 独立 in_proj/循环/out_head） |
| 失败机制 | 增长节点从未形成独立能力 | 结构调整过频（spawn+merge 震荡）压过学习 |
| 结论 | 增长机制无系统性优势 | 在此实现下「全动态」亦无优势，但失败点**换了** |

即：FDN-v0 本轮**成功修复了 GSLM 指出的"共享投影"缺口**（路由模块化真实成立），却暴露出**新的缺口**——**在线结构演化的稳定化**。这本身是有价值的机制级发现。

## 5. 局限与混杂（如实声明）

1. **"forgetting on A" 被序列终点污染**：序列以 `A2_add`（加法变体）收尾，末次训练就是加法，故各模型终点的 `A_add` 准确率实为"A2 表现"。A(MLP)=1.0 是"重新学加法"；C=0.055 是"重调用的节点没学会"。`forgetting_A` 数值（C=0.097）**不具意义**，因为 C 的 `acc_A_init` 本身近随机（0.061）。真正的对比是"终点 A_add"：A=1.0 > D=0.574 > B=0.125 > C=0.055。
2. **MoE 族比 MLP 更难学**：B/D/C（路由 top-k + per-sample 循环 + 门控）学习明显慢于稠密 MLP（A 轻易到 1.0）。因此"C 是 MoE 族最差"是真实，但不能简单归因"动态比静态差"——更准确是"动态加成在该学习速率下是净负担"。
3. **单 seed**：本报告只有 seed=0。结果方向性强（C 全场最差），但复现性未做多 seed 验证。
4. **toy 规模**：参数 <8 万、4 个 toy 任务，容量充足。与 GSLM 一致，未做"容量成瓶颈"档位（更长序列/更大任务数）验证。

- **若目标是证伪**：结论"FDN-v0 在本实现+toy 任务集未获支持"成立，可引用本条反证收尾。
