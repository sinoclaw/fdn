# FDN-v0.4-lite 实验结果报告（软任务亲和，如实版）

> 本报告与 `results/summary_v04lite.json`（原始数据）、`model/fdn.py`（soft task bias 实现）、`experiments/continual.py`（--profile v04lite）形成三层对账，供外部审计（GPT）核定。
> 依据：v0.4 硬隔离被反证（node_overlap_A_A2=0.0 破坏 A/A' 复用）→ 拍板修正方向 = **软任务亲和**（不硬屏蔽，用可学习 task_emb 加 query 偏移）。

---

## 0. 一句话结论

**软任务亲和（soft task bias）方向正确，且存在最优强度 w=0.5——它是 FDN 迄今最好成绩。** 完整扫描 w ∈ {0.3, 0.5, 0.8}：w=0.5 同时做到 **A=0.545（超 v0.2-B 的 0.455 纪录）+ forgetting=0 + B=0.209（v0.2-B 的 10 倍）+ A2=0.477 + node_overlap_A_A2=0.7（A/A' 复用完整）**。w=0.3 太弱（A 被 B 挤占，A=0.104）；w=0.8 太强（task_emb 主导路由，破坏 A/A' 复用，A=0.020/遗忘0.75）。**软偏强度有最优峰值 w≈0.5。**

## 1. 机制（FDN-v0.4-lite 软任务亲和）

- **soft task bias**：`q = W_q·x + w·task_emb[task_id]`（task_emb 为可学习 Embedding，初始小偏移），**不硬屏蔽**（task_constraint=False）。
- 保留 v0.3 全部机制：per-node protected routing（未成熟 warm/成熟 protected）+ Competence Lock + Re-activation。
- `set_task` 在任务边界/评估时注入 task_id → 软性鼓励不同任务偏向不同 Node 组，但**允许跨任务复用**（保住 A/A' 调用）。

## 2. 设定

- `--seq core --profile v04lite --seed 0 --n_train 1200 --epochs_per_task 40 --soft_task_bias <w> --run C`，w ∈ {0.3, 0.5, 0.8}。
- 对照：v0.2-B（A 0.455）、v0.3（A 0.285）、v0.4 硬隔离（A 0.023 反证）。

## 4. 判定

- **w=0.5 最优**：A=0.545（超 v0.2-B 纪录）+ forgetting=0 + B=0.209（v0.2-B 的 10 倍）+ A2=0.477（A' 调用）+ overlap=0.7（A/A' 复用）——**「软偏强度最优峰值」实证**，同时保住跨任务复用 + 让难任务学得更多。
- **w=0.3 太弱**：软偏不足以把 B 分流，A 反而被 B 挤占（A=0.104）。
- **w=0.8 太强**：task_emb 主导路由 → 破坏 A/A' 复用（forgetting=0.75）。
- **综合**：v0.4-lite w=0.5 是 FDN 迄今最优，**回应 GPT 目标**（A 保留 + B/C 学到 + A/A' 复用）最接近。

## 5. 下一步

- w=0.5 已确立为软偏最优；可再细分 {0.4, 0.6} 精细定位。
- C_logic 在 w=0.5 时仍偏低（0.002）——布尔逻辑任务难学，且 soft 偏时 C 未独立；建议交 GPT 审计，裁定「C 是否需要任务专属 Node 折中」。
