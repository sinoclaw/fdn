# FDN-v0.5 批次 1：多 seed 复现报告（MULTISEED，如实版）

> 配置：`v04lite, w=0.5, n_train=1200, 40ep, core 序列 A→B→C→A'`，seed = 0..5。
> 依据 GPT v0.5 判据：5/6 seed 达 `A_end>0.4 / forgetting≈0 / A2>0.35 / B>0.15`。

---

## 0. 一句话结论（重要反证）

**w=0.5 的「漂亮信号」不能跨 seed 复现——seed0 的 A=0.545/遗忘0/overlap 0.7 是偶然。** 6 个 seed 中 **仅 seed3 达标**（A=0.973、遗忘0、A2=1.0），其余 5 个均未达标：A_end 跨度 0.018→0.973，forgetting 从 0 到 0.904，B 普遍 <0.1（远低于 0.15）。**GPT 的警告被验证：最大不确定性正是「w=0.5 能否跨 seed 重现」——答案是不能。**

## 2. 诊断：为什么巨大变异

### 2.1 不是"学习"差异，是"A' 是否复用了 A 的 node + A 是否被覆盖"
对比好（seed3）vs 差（seed0）：

| | A_curve | A 的"真实"学习 | 定性 |
|---|---|---|---|
| seed3（好） | [0.08, 0.041, 0.064, **0.973**] | A 一直没学会（~0.04-0.08） | **A=0.973 是假象**：A' 恰好命中大输出 node 才虚高 |
| seed0（差） | [0.184, 0.088, 0.02, **0.018**] | A 一开始略好，被 B/C 覆盖衰减 | A 被后续任务覆盖遗忘 |

### 2.2 根因：全部 6 seed 的 `task_affinity_disjoint_frac = 0.0`
**A/B/C/A' 用同一批 node，根本没有模块分化（disjoint=0）**。这正是 GPT 反复指出的"B/C 未形成独立模块"。
- seed3: task_node_groups 里 A/B/C/A' 命中 **几乎同一批**（如 [1,2,6,7,9,10,11,12]）。
- seed0: [0,1,2,3,6,9,12,13,14] 等也高度重叠。

### 2.3 变异来源 = 初始 node 随机种子
A 是否在"合适"的 node 上成型、B/C 训练时是否覆盖 A，高度依赖 torch 初始化的随机种子。seed 变化 → 首任务 A 落在不同 node → 后续覆盖情况不同 → A_end/forgetting 剧烈波动。

## 3. 判定（对照 GPT 判据）

| 判据 | 阈值 | 实测 | 达标? |
|---|---|---|---|
| A_end | >0.4 | 仅 seed3 (0.973) 达标 | ❌ 1/6 |
| forgetting≈0 | <0.05 | seed1/2/3/4 达标，seed0/5 爆 | ⚠️ 部分 |
| A2 | >0.35 | seed2/3/5 达标 | ⚠️ 3/6 |
| B_mul | >0.15 | **全部 <0.1** | ❌ 0/6 |
| overlap | >0.5 | 4/6 达标 | ⚠️ 部分 |

**结论**：**多 seed 复现判据未通过。** B 全部不达标（0/6），A_end 仅 1/6 达标，且存在严重 seed 敏感性（差异 >50 倍）。

---

## 4. 关键意义

- **w=0.5 不是跨 seed 稳定解**（GPT 预警被证实）。
- **root cause 不是 w 强度，而是「任务间没有真模块分化」**——6 seed 全 disjoint=0，A/B/C 共享同一批 node，这是「B 学不好 + A 被覆盖/假象」的共同根源。
- **下一步不能继续在 w 上打转**，而应回到 GPT 的核心：**让任务真正分化到不同 node 组（Module Specialization）**——这正是批次 3 的 Node Specialization Matrix 要直接测量的指标。
- 这也说明 **FDN 当前架构下，"模块分化"尚未发生**——不解决分化，多 seed 永远不稳定。
